# volante/eletronica

Esquemas elétricos, pinagem detalhada e lista de componentes.

Kit eletrônico (Fase 1): 2 Raspberry Pi Pico, 15 botões táteis, 15 diodos 1N4148,
5 encoders EC11, 3 sensores SS49E (Hall), 2 protoboards, ímãs N52.

> Na Fase 8 a fiação ponto a ponto vira **PCB** (arquivos Gerber/BOM aqui).
