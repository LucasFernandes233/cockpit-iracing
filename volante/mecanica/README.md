# volante/mecanica

Modelo 3D e documentação mecânica do volante. Modelo paramétrico em **CadQuery**.

**Arquivos (✅ presentes):**
- `modelo_volante.py` — modelo paramétrico (CadQuery); regenera tudo a partir dos parâmetros
- `volante_P1_montagem.step` — montagem completa · `pecas_step/` — peças avulsas (STEP)
- `relatorio_verificacao.txt` — folgas/interferências e massas (~458 g impresso + chapas)
- `LEIA-ME.txt` — como abrir no SolidWorks, sistema de coordenadas, o que fabricar
- `previa_volante_P1.png` — prévia do modelo
- `placa_frontal_layout_MVP_rev00_A3.pdf` / `_2xA4.pdf` — desenho 1:1 da placa (maquete, Fase 2)
- `aleta_mecanismo_rev00.pdf` — conceito e cálculos das aletas

> Arquivos de fabricação (STL/DXF) ficam em [`../fabricacao/`](../fabricacao/).
