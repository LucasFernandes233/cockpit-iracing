# 🏎️ Cockpit iRacing

Projeto de criação de um **cockpit de simulador de corrida do zero** — da modelagem 3D
das peças físicas até o software/firmware que dá vida aos controles.

O desenvolvimento começa pelo **volante** e segue para as demais peças do cockpit.

## 📁 Estrutura do projeto

| Pasta | Conteúdo |
|-------|----------|
| `hardware/` | Modelagem 3D (FreeCAD), peças para impressão (STL) e eletrônica de cada componente |
| `hardware/volante/` | 🔧 **Começo do projeto** — CAD, STL e eletrônica do volante |
| `firmware/` | Código do microcontrolador (ex.: Arduino) que lê botões/encoders e comunica com o PC |
| `software/` | Software de PC: configuração, telemetria, integração com o iRacing |
| `docs/` | Documentação, medidas, decisões de projeto e imagens de referência |

## 🗺️ Roadmap
